# Cohort Analysis for Customer Retention

## Overview  
This project performs a cohort analysis on an eCommerce dataset to explore customer retention trends and behavioural patterns across different user groups over time. The objective is to support Customer Lifetime Value (CLV) prediction and guide the development of data-driven retention strategies.

## Key Features  
- 📊 **Cohort Analysis**: Grouped customers by acquisition month and tracked retention behaviour over subsequent periods  
- 🔍 **CLV Prediction**: Estimated customer lifetime value using machine learning models  
- 🧠 **Behavioural Insights**: Uncovered trends to support targeted retention efforts  
- 📈 **Visualisation**: Clear visual representation of cohort retention rates over time

## Technologies & Tools  
- **Python**  
  - Pandas & NumPy for data manipulation  
  - Seaborn & Matplotlib for visualisation  
- **Machine Learning**  
  - XGBoost  
  - Random Forest  
- **Customer Analytics**  
  - RFM and CLV modelling

## Approach  
1. **Data Cleaning & Preparation**  
   - Processed transactional data to extract customer activity and purchase behaviour  
   - Created cohorts based on acquisition month  

2. **Cohort Retention Analysis**  
   - Calculated retention rates for each cohort  
   - Visualised trends in customer retention over time  

3. **CLV Prediction**  
   - Engineered features based on cohort behaviour  
   - Applied XGBoost and Random Forest to model and predict CLV  

4. **Insight Generation**  
   - Interpreted results to recommend retention strategies  
   - Identified high-value segments for targeted engagement

## Results  
- Identified cohorts with the highest drop-off rates  
- Predicted CLV for different customer segments  
- Provided actionable insights to improve retention and marketing effectiveness
